# tv80-player

Página player da TV anos 80 do Second Life: põe um vídeo do YouTube ocupando a
tela inteira da TV.

O YouTube só aceita vídeo incorporado (`/embed/`) dentro de um iframe numa página
com endereço de verdade — aberto direto na mídia do Second Life, dá erro 153.
Esta página é esse endereço.

Uso: `player.html?v=ID_DO_VIDEO` ou `player.html?list=ID_DA_PLAYLIST`.
